# Solvay 1927

A historically grounded simulation of the 1927 Solvay Conference. See README.md and docs/.

- History lives in `data/` as JSON; never put beliefs, quotations or citations in code.
- After editing `data/`, run `npm run check:data`. Before pushing, run `npm test` and `npm run typecheck`.
- Never invent quotations. Voice lines are paraphrase and must not use quotation marks.
- New projects do not belong in this repository; ask for a separate one.
